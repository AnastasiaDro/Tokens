# Логирование

- Читать корневой `AGENTS.md`. Сохранять разделение контрактов Logger/LoggerFactory и Android-реализации.
- Не добавлять зависимости на фичи и UI. Не менять контракт только ради удобства одного вызывающего места.
- Не логировать содержимое пользовательских фото, секреты и чувствительные данные.
- Ошибки медиа и хранения должны быть диагностируемы, но логирование не должно менять бизнес-результат.
- Выносить api/impl в отдельные Gradle-модули только при соответствующей задаче.
- Минимальная компиляция — `:core:logger:compileDebugKotlin`.
