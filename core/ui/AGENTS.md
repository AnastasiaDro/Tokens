# Общий UI

- Читать корневой `AGENTS.md`. Здесь только компоненты и утилиты, действительно общие для нескольких потребителей.
- Не добавлять зависимости на feature-модули, их ресурсы и бизнес-модели.
- Fragment-утилиты для работы с View должны использовать lifecycle именно View. Подписки не должны дублироваться при пересоздании View.
- При переходе на Compose переносить сюда общую тему и переиспользуемые компоненты; UI жетона оставлять в фиче до появления других потребителей.
- Старые Fragment/navigation/permission-утилиты удалять после миграции всех их вызовов.
- Проверять затронутые потребители; минимальная компиляция самого модуля — `:core:ui:compileDebugKotlin`.
