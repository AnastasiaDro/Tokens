# Общий UI

- Читать корневой `AGENTS.md`. Здесь только компоненты и утилиты, действительно общие для нескольких потребителей.
- Не добавлять зависимости на feature-модули, их ресурсы и бизнес-модели.
- Fragment-утилиты удалены. Подписки не должны дублироваться при пересоздании композиции или back-stack entry.
- При переходе на Compose переносить сюда общую тему и переиспользуемые компоненты; UI жетона оставлять в фиче до появления других потребителей.
- Общая Compose-тема — `theme/TokensTheme.kt`: сохранять светлое оформление существующего AppTheme, не включать динамические цвета или тёмную тему без отдельной задачи. Общие цвета и размеры — TokensColors и TokensDimensions; параметры поля жетонов сюда не переносить.
- Новые экраны размещать в Compose NavHost с TokensTheme. Сохранённый общий адаптер `setTokensContent` для View-host привязывает композицию к View lifecycle и требует стабильного resource ID для rememberSaveable; он покрыт инфраструктурным тестом, не создаёт ViewModel и не управляет навигацией.
- Compose UI-тесты находятся в `ComposeInfrastructureTest`; запускать их при изменении темы или адаптера жизненного цикла.
- navigationViewModel связывает NavBackStackEntry с существующими Koin-определениями через AndroidX viewModelFactory/CreationExtras; не использовать Activity-wide ViewModel для диалогов. SavedStateHandle создаётся для entry, затем передаётся как параметр Koin. NavigationDialog перехватывает Back и внешние нажатия, отключая автоматическое pop стандартного navigator; callback должен проверять текущее состояние VM, а не устаревший Compose-снимок.
- PhotoPreview используется диалогом фото и полем жетонов: локальный URI, ImageDecoder на Dispatchers.IO, ограничение длинной стороны 1024px, состояние загрузки/недоступности без изменения сохранений. Новый URI сразу сбрасывает прежнее изображение, отменённая загрузка не должна публиковать результат. Не добавлять сетевую загрузку или синхронное декодирование в Compose render. Проверять PhotoPreviewTest при изменениях.
- View-based SwipeParser, PermissionsManager и ImageView/setPhotoImage удалены. Не возвращать параллельную View-реализацию; ComposeView-адаптер сохранён как проверяемая общая утилита, но текущие экраны больше не используют Fragment.
- Проверять затронутые потребители; минимальная компиляция самого модуля — `:core:ui:compileDebugKotlin`.
